#
# 规则：父目录下递归（最多 4 层）找名字是 8 位日期（YYYYMMDD）的目录，当成“一天”；
#       名字里带「未验证 / 不可用 / 其他文件 / 标定文件 / 模板 / error」等目录会跳过；
#       里程文件完整性预检：缺轨迹 / 2M / 8M 任一项就跳过并写日志，不分析。
#       可加 since=YYYYMMDD，只处理该日期及之后的新数据（更早的忽略）。
#
